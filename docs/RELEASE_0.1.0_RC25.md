# RC25 candidate validation

RC25 adds consumer-configured character restoration, wardrobe previews, skills,
timed attack inputs, encounters, rewards, party recruitment, and cinematic routing.
Story content is supplied by mod packages. No campaign ships in the SDK.

This is an unpublished test candidate. Source tests and native fixture checks
have passed; packaged and gameplay compatibility results must be reviewed before
publishing. The runtime and controller use native protocol version 318.

Install by extracting the SDK ZIP at the game root. It includes the bootstrap,
bundled Python, and three core mods. Optional mods are a separate ZIP.
No saves, settings, user maps, development logs, or local personal mods are shipped.
